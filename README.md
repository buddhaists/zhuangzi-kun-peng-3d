# 《莊子‧逍遙遊》北冥有魚 — 鯤鵬化雲 3D 群鳥動態藝術

> 「北冥有魚，其名爲鯤。鯤之大，不知其幾千里也。化而爲鳥，其名爲鵬。鵬之背，不知其幾千里也；怒而飛，其翼若垂天之雲。」——《莊子‧逍遙遊》

以 **Three.js** 與 **自訂 WebGL GLSL Shader** 演繹八萬五千隻飛鳥於灰藍陰鬱天幕中凝聚成巨鯤、翻湧化為大鵬、雙翼展開如垂天之雲的五幕 3D 視覺震撼體驗。畫面嚴格考究野外紀錄片與鳥群自然聚散（Murmuration）的遠景長焦寫實質感。

---

## 視覺特色與技術亮點

### 1. 85,000 隻飛鳥 GPGPU / Custom Shader 粒子流體演繹
- **雙重 3D 形態演算法（Dual-Morphing Geometry）**：
  - **巨鯤（Kun）**：左側尖銳魚吻、飽滿深沉的弧形魚腹、微弓平緩的背脊與右側分叉延展的流線尾鰭。
  - **大鵬（Peng）**：向左上方天際刺出的修長前緣翼尖、厚重胸背、以及向右延展的三層階梯狀飛翼羽煙（「其翼若垂天之雲」）。
- **3D 渦流旋轉場（Curl Noise Swirl）**：模擬真實椋鳥群內部的明暗疏密波紋、邊緣銳利凝集（Limb Darkening）與變形時的翻騰旋流。
- **飛鳥個體振翅 Shader**：在 Fragment Shader 中即時繪製帶有各別隨機相位差與側傾角（Banking Tilt）的展翅剪影（V 字揚翅至 M 字拍翅動態），邊緣逸散的巡邏鳥（Scout birds）可清晰辨識其展翅姿態。

### 2. 考究遠景紀錄感的環境與雙地景剪影
- **灰藍冷冽層雲天幕**：自訂 FBM 球頂天空 Shader，呈現自然寫實的陰鬱天幕與低速移動的層雲陰影。
- **雙前景地標自然轉場**：
  - **觀海涼亭（Coastal Pavilion）**：前兩幕佇立於右下方，內部有駐足遠眺的人群剪影，凸顯巨鯤於天際游動的壓迫尺度。
  - **曠野電線桿與鳥巢（Field Utility Poles & Osprey Nest）**：隨鏡頭橫移至第四、五幕，右下方過渡為雙柱電線桿、頂部大型鳥巢、以及成排停棲在下垂電線上的微小飛鳥剪影。

### 3. 東方古典排版與完整導演控制介面
- **古典直排宋體詩詞面板**：以傳統直排格式浮現《莊子‧逍遙遊》五句原文，隨動畫進度自動高亮對應章節與白話意境解析。
- **五幕時間軸自由導覽**：
  - 壹 · 北冥潛鯤（北冥有魚，其名爲鯤）
  - 貳 · 幾千里也（鯤之大，不知其幾千里也）
  - 叁 · 化而爲鳥（化而爲鳥，其名爲鵬）
  - 肆 · 鵬之背（鵬之背，不知其幾千里也）
  - 伍 · 垂天之雲（怒而飛，其翼若垂天之雲）
- **環境與視角控制**：
  - 氣流渦旋（Curl Turbulence）、群鳥凝密度（25,500 ~ 85,000 羽）、蒼穹風速自由微調。
  - 多機位預設：五幕自動敘事運鏡、觀海涼亭定點、長焦特寫巨鯤首部、曠野電桿仰望大鵬、自由 3D 軌道視角（支援滑鼠旋轉與滾輪縮放）。
- **Web Audio API 程序化音場**：內建北冥海風與數萬飛鳥振翅掠過天際的低頻音浪（快捷鍵 `M` 隨時開關）。

## 鍵盤快捷鍵

| 按鍵 | 功能說明 |
| :--- | :--- |
| `Space` | 播放 / 暫停五幕自動推進 |
| `1` ~ `5` | 快速跳轉至第一幕～第五幕 |
| `M` | 開啟 / 關閉環境音場（風聲與振翅聲） |
| `R` | 復位至最佳敘事運鏡機位 |
| `H` | 隱藏 / 顯示控制介面（純享畫面模式） |

## 本地運行方式

本專案完全零依賴構建工具，包含完整的自我封裝 `lib/` 庫，複製即可直接運行：

```bash
# 使用任意靜態 HTTP 伺服器開啟目錄
python3 -m http.server 8080
# 或使用 Node.js / npx
npx serve .
```

在瀏覽器中開啟 `http://localhost:8080` 即可欣賞。
